#### M-D10-01 N+1 创新　[核心卡]

- 所属：D10-1｜主分类：对外｜稳定度：永恒原理
- 能力标签：做、思｜辅助标签：—

1. **解决什么问题**：把创新误解为从 0 到 1 的凭空发明。
2. **原著核心判断**：创新是 **N+1**——在已有 N 上做出前人未做到的一点；须先复现 N 的最成功基准再证明改进（学术与产品同源论述）。
3. **前提与边界**：「从 0 到 1」语义见富足专论，不与本章混淆（F 台账）。
4. **出处**：C-SG3-U0173-、C-SG1-U0335-（N+1工作/基准实验）
5. **落地映射（映射·非原著）**：产品迭代：先对齐行业基准体验，再做一个可度量 +1。

#### M-D10-02 牙刷与爆款　[核心卡]

- 所属：D10-1｜主分类：对外｜稳定度：永恒原理
- 能力标签：做｜辅助标签：—

1. **解决什么问题**：产品只有大爆炸无留存，或只有小修小补无惊喜。
2. **原著核心判断**：**牙刷**（高频可靠小价值）+ **爆款**（周期性大惊喜）组合；职场应用见 M-D06-03。
3. **出处**：牙刷原则/爆款效应增长门簇（GG/JS/SG1）
4. **跨书关系**：F-050 与三句话汇报。
