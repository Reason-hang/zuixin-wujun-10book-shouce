# 第六章 心智的成长

在同一环境中长大的孩子，无论是从家境、早期受到的教育还是从机会上看，都差不了太多。由于父母的层次差不多，这些人在智力上也没有太大的差异。但是经过一代人的发展，他们在生活水平、个人成就、家庭幸福等各方面会出现巨大差别，造成这个结果的原因主要在于每个人不同的成长经历。

成长首先看环境，而在环境的因素中，首先且最重要的是家庭环境和朋友圈，其次要看自身做事的原则和方法。天天彳故冒险的事情，早晚有一天会付出失败的代价，而太多的失败则会导致习惯性失败。相反，永远待在舒适区，只会让人无法成长。每个人的成长，最终是在边界内最大程度上把事情做好。
