## 第215封信｜蒙田告诉你，少在意无关紧要的事情

读者，你好。

欢迎回到《吴军来信》第二季。

我们在昨天的来信中讲了，人不要脑子欠，很多不重要的事情，不要胡思乱想。那么，怎么才能做到这一点呢？这就要讲到一位先哲的思想了，这个人是法国启蒙作家蒙田。

**蒙田其人与思想**

今天，人们给蒙田贴上了不少的标签，包括启蒙哲学家、人文主义作家、怀疑论者等等。其实蒙田的哲学思想并不成体系，因此他和稍晚一点的笛卡尔，在哲学上是不能相比的。我个人认为，蒙田最重要的身份是人文主义作家。蒙田出生在一个富商家庭，受过良好的教育，精通希腊语、法语和拉丁语。他有间断的从政经历，担任过宫廷的顾问和波尔多市的市长，但是因为身体不好，大部分时间在旅游和修养。在此期间，他写下了一生主要的著作《随笔集》。

蒙田的思想和中国的道家学说有些相似之处。蒙田是一个超脱的人，把一切都看得很轻，对仕途也没有太多兴趣，放弃了大好的政治前途，一头扎进自家的书斋潜心读书写作，过起了隐居的生活。这个举动有点像中国的隐士陶渊明，当时很多人对这种做法并不理解。然而他那种既超脱尘世，又看重现世生活，强调人的价值的想法和做法，却让后世很多作家称赞不已。

蒙田留下了很多名言，其中有一句，《随笔集》的英文版本是这么说的，“Nothing fixes a thing so intensely in the memory as the wish to forget it”，这句话直译过来是说，一件事你越是想要忘记，它越是会深刻地留在记忆里。而我更倾向于它的意译版本，“当你停止在意，一切自然归位”。我觉得这句话特别体现出他的人生智慧。

**放不下，是人生苦源**

今天大部分人，对很多事情都太在意了，在意别人对自己的看法，在意身边人比如父母和子女的生活，在意自己当下的生活意义，在意将来，也在意过去一些经历对自己留下的阴影，等等。

比如，很多人花了一辈子的时间，努力融入别人，希望被别人认可，结果是把自己变成了一个不属于自己期待的样子。你不妨想想，是否曾经因为担心别人的想法，不敢说出自己的想法。

又比如，很多人为自己的子女操心了一辈子。子女都三四十岁了，他们还在操心。而他们的子女，却是不胜其烦。

再比如，很多人没有考上好大学，就有一种挫败感。但其实站在一个客观的角度来看，可能当时的准备、资源或者状态，确实还不够上好大学。因此，这种挫败感只是因为当时设定了不合理的目标。

总的来说，操心、思虑太多是一种常见困扰。很多人，花了很多时间和精力，去担心自己不该担心的事情，这种事情包括三类：

第一类，是在生命中微不足道、并没有深远影响的事情。比如今天小王在办公室里让我下不来台。这些事情几乎每天都会发生，如果太在意，生活一定很压抑。

第二类，是担心了也没有用的事情。比如成年子女的未来，或者得了绝症之后生命的长度。儿孙自有儿孙福，父母没办法为他们保驾护航一辈子，更何况，过分的关心常常还会起到反作用。至于生命长短，每个人都想活得长久，但生命终有终结，也是改变不了的。你如果是一位医生，会很清楚一个绝症病人能活多长时间，操心、担心，都没有用；但你也会发现，几乎没有人接受你的看法。

第三类，是本来就不属于自己的东西。比如我们前面提到的好大学，或者不属于你的恋人等等。

**人们之所以会担心或者操心这些事，是因为人有很强的控制欲，总是想控制自己的未来，控制世界上的未知事物。**

举个例子，有很多人热衷于算命、看星座，就是因为那些人试图通过算命，来知晓未来明明不确定的事情。世界上有很多事情，并不是像明天太阳一定会升起那样可预测，或者可控制。就像很多体育比赛的结果，常常不到最后一分钟，结果就是未知的，有变数的。而你作为电视机前的观众，无论怎么求菩萨保佑，也不能帮助自己下注的队伍取胜。还有很多事情，虽然结果是确定的，而且可能已经确定了，却是由别人决定的，你着急也没用。比如单位最近在提职称，结果已经确定了，但还没有通知到普通员工，你还不知道。这个时候，不管你是放宽心，还是干着急，得到的是同样的结果。既然如此，何必要为它焦虑呢？

**放下执念，拥抱真实和自由**

蒙田发现，人们通常有两个弱点。

第一，人常常成为自己想法的囚徒，动不动就陷入无尽的担忧。一方面，人们明知道生活有很多不确定性，另一方面却还要死死抓住控制权。我们前面的例子，都反映出人类的这个弱点。

第二个弱点，是拼命追求一种不属于自己的成功标准，特别是渴望最好、最完美的东西。比如很多人找结婚对象，提一大堆要求，全世界能满足那种要求的，根本也没有几个人。很多人之所以条件很好，也渴望结婚，但到了很大的年龄还是单身一个人，就是非要找到一个完美的伴侣。但我们知道，世界上很多事情都是不完美的，周围人的婚姻也不是完美的，凭什么我们得到的就必须完美？还有少数人，不仅要别人完美，还对自己过于苛刻，要求自己完美，这其实也是办不到的。

对此，蒙田展开了逆向思维，如果我们根本不在乎这些事，会怎么样呢？当你不再在乎完美，就会开始接纳周围的人，也会接纳自己的缺点。当你不再在乎外界的认可，你就开始为自己而活。就像蒙田说的，其他人把感情分散在数不清的知亲好友身上，分散在自己的功名富贵问题上，而我全放在自己和自己的精神安宁上。

当你不再试图掌控一切，你就发现世界其实非常大，一切皆有可能。这种辩证的思想，很像道家的学说，你越少试图证明自己，你就越强大。你不妨看看身边那些最自信，最有人格魅力的人，是否总在寻求认可，寻求控制一切。他们看起来都是轻松自在的，不被小事所困扰，而且活得真实。

现代心理学表明，人们都喜欢和“真实”的人打交道。你会被他们的真实所吸引，并不会要求他们完美。既然如此，我们何必希望周围的人把我们当完美的人来看待呢？蒙田了不起的地方在于，在这个道理被揭示出来之前，他就根据自己的经验，早早洞悉了人性的奥秘。蒙田认为，当你摆脱对于失败和他人看法的恐惧，就会获得一个最宝贵的东西——自由。

我们每一个人都渴望自由。但是，真让一个人自由地去做事情的时候，他又瞻前顾后，担心失败；让一个人自由地讲出心里话的时候，他又担心别人的看法；真让他自由生活的时候，他又会去操不必要的心。这仿佛是一个悖论。

但事实上，只要一个人放下执念，不再过度忧虑，内心就会平静，就能集中精力做自己喜欢的事情；同时，人际关系也会改善，机会也就会随之而来。如果你要做决策，因为放下了执念和琐事的烦恼，这时候决策就是基于你的真实想法，你做起来会很轻松，也会对你最有利。

今天，很多人做决策的时候总是犹豫不定，就是因为考虑的琐事太多。一项决定，如果想要满足所有的条件，那就难了，把不重要的琐事从考虑的清单上删除，做决定就容易多了。人一辈子的道路，就是一次次抉择的结果。每次做决定都被琐事干扰，必然影响抉择的结果。很多人每次到了分岔口，总是选一个最差的结果，就是因为太在意琐事了。

蒙田除了劝我们放下执念，不要被琐事干扰，还告诫人们，不要把生活塞进一个不适合它的框架。我在第107 封信中讲过，今天社会上有很多其实不需要的所谓“刚需”。那些并不需要的刚需，放在一起，就是一个不适合我们生活的框架。人们常常有很多烦恼，有些是来自于现实本身，有些则是来自于社会和环境在我们头脑里的幻象。为这些幻象去奋斗，不值。

当然，蒙田讲的不在意，并不意味着要过懒散和逃避现实的生活。蒙田认为，人应该接受不完美，接受不确定性，然后去过一种真实、轻松的生活。蒙田注意到，有些人成功似乎是轻而易举的，而有些人拼尽全力却还在痛苦中挣扎，这倒不完全是能力的差异。而是前一种人轻装前行，后一种人包袱太重。你可能注意到一个现象，有时候你越是刻意追求什么，常常得不到，但是如果你用一种轻松的心态去对待它，那件事可能反而办成了，那个想要的东西也就得到了。

结合我们昨天讲的，不要脑子欠。想想蒙田给我们的建议，越是放下外在的压力和内在的执念，越能找到真实的自己，获得的结果就越好。人生是不可预测的，完美是一种幻觉，而自我接纳才是最高形式的智慧。

好，这封信就先和你说到这里。下一封信我想再和你聊聊底层逻辑这件事，我们下一封信再见。
